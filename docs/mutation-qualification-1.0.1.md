# CPCF 1.0.1 mutation qualification

Version 1.0.1 requires the normal complete mutation qualification gate. The
[owner waiver](mutation-exception-1.0.md) is a historical record for 1.0.0 only.
It supplies no passing mutation evidence for either version.

The patch strengthens regressions for observable control boundaries:

- onboarding preserves every subsystem status, exact blocker set, unresolved
  human decision and read-only recovery command;
- OIDC device polling binds the endpoint, client, grant and device code, checks
  inclusive response bounds and stops at expiry without writing credentials;
- epistemic inspection retains correlated hypotheses, reports exact rational
  bounds and universal enablement, and never grants execution authority or
  resolves empirical attribution.

These are synthetic software tests. They do not establish production assurance,
external capability creation, measured collective-intelligence acceleration,
AGI or ASI. The maintained public API, Beta classification and `cpcf.io/v0.6`
protocol identity are unchanged.

## Evidence required before publication

logical shards must succeed against the same revision, configuration and full
catalogue. Preserve the isolated source hash manifest and import-origin checks.
The merger rejects missing, overlapping, incomplete and foreign-catalogue
reports. The independent scope check and unchanged aggregate 85% floor are
mandatory. A tool exit code or catalogue fingerprint alone cannot qualify a run.

`bac5c7a52347be74c53590a0bd8e53f285d05ef48ef80795d5bf9b42eaa64cd3`.
